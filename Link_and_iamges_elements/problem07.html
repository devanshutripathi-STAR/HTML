Python Programming Fundamentals

Overview

This beginner-friendly course introduces Python programming and helps learners develop logical thinking through practical examples.

Students will learn variables, data types, conditional statements, loops, functions, lists, dictionaries and basic file handling.

No previous programming experience is required. Basic computer knowledge and a willingness to practise are recommended.
