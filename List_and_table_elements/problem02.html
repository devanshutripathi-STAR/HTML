Admission Overview

This handbook provides general information about university admission, required documents, application steps and fee structure.

Visit the official university website for current admission information.

Students should verify eligibility, fees and deadlines from official university announcements before applying.

Eligibility

Mandatory: Applicants must fulfil the eligibility requirements of their selected programme.

Application deadline: Check the official admission notice.

Required Documents

  • Class 10 mark sheet
  • Class 12 mark sheet
  • Identity proof
  • Passport-size photograph
  • Transfer certificate, if required
  • Category certificate, if applicable

Application Process

  1. Visit the official admission website.
  2. Register using your email address and mobile number.
  3. Fill in the application form.
  4. Upload the required documents.
  5. Pay the application fee.
  6. Submit the completed application.
  7. Save the application confirmation.

Important Terms

Eligibility
The conditions a student must satisfy for admission.
Merit List
A list prepared according to the applicable selection criteria.
Counselling
A process in which applicants receive admission guidance or seat allocation.
Scholarship
Financial assistance provided according to specified conditions.
Registration
The process of submitting details to begin an application.
